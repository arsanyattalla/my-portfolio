# Arsany Attalla — Interactive Portfolio

React + Vite portfolio focused on network engineering, infrastructure, automation and cybersecurity.

## Run
npm install
npm run dev

## Customize
- Change `hello@example.com` in `src/main.jsx`.
- Add GitHub/LinkedIn links.
- Add real screenshots/case studies in the project modal.
- Add your resume PDF and link it from the CTA/navigation.

## Features
- Animated network-core hero
- Live simulated uptime and packet metrics
- Project search/filter
- Interactive case-study modals
- Ctrl/Cmd + K command palette
- Responsive mobile layout
- Timeline and skills sections
